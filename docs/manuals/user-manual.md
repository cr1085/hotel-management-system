# Manual de Usuario

## Introducción

El sistema permite administrar hoteles y sus configuraciones de habitaciones de manera sencilla mediante una interfaz web responsive.

---

# Pantalla Principal

Al ingresar al sistema, el usuario podrá visualizar:

- Formulario de creación de hoteles
- Listado de hoteles registrados
- Configuraciones de habitaciones por hotel

---
