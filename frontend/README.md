# Hotel Management System - Frontend

Frontend application developed for the Decameron Hotels technical test.

This project allows hotel management and room accommodation configuration through a modern and responsive web interface connected to a Laravel REST API.

---

# Technologies Used

- React
- TypeScript
- Vite
- TailwindCSS
- Axios

---

# Main Features

- Hotel registration
- Hotel listing
- Room configuration management
- Accommodation validation rules
- Responsive design
- Dynamic notifications
- REST API integration

---

# System Requirements

Before running the project, make sure the following software is installed on your computer:

## Required Software

- Node.js (version 18 or higher recommended)
- npm
- Git
- Backend API running correctly
